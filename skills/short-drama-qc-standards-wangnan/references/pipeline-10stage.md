# 第 0 套：全链路通用基线（10 阶段，所有题材共用）

适用：剧本 → 分镜 → 生图 → 图生视频 → 剪辑转场 → 字幕 → 音频 → 成片 → 上线终审 → 异常兜底，覆盖抖音漫剧 / 3D 写实漫剧。
定位：**常驻层**。所有题材项目都叠加这一套；题材基线（第 1～14 套）在它之上做专项加严，不替代它。
分类：`必检` = 每次都要过；`风险复检` = 命中风险镜头必查；`上线终审` = 交付前最后一关。
签字栏：每项都要落「核验人 + 日期 + 结论」，不许空。

## 口令

- **叠加加载**：`sd-qc-engine，加载《全链路通用基线V1（10阶段）》作为常驻层，同时加载《<题材>质检清单V1》作为专项层；两层合并成一份生效清单，专项层只加严不豁免；开启前置盘点与后置审计。`
- **分阶段跑**：`sd-qc-engine，加载生效清单，本次只跑第 <N> 阶段（<阶段名>），逐条出结论与签字栏，其余阶段不跑。`
- **整集全链路**：`sd-qc-engine，加载生效清单，按一～十阶段顺序全跑；每阶段出小结与签字栏；风险复检项必须命中检查；上线终审项必须人工签字；末尾出技能调用审计栏与兜底复检建议。`
- **出问题专项**：`sd-qc-engine，执行第 10 阶段专项复检表 <10-x>，只查该项，出具现象与证据（段/镜号）。`
