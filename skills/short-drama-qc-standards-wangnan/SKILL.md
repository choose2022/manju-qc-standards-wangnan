# 漫剧全题材质检基线合集

作者：wangnan

这个 Skill 是一份**可切换的质检基线库**：14 套题材清单，每套自带「检查项 + 合格标准 + 缺陷等级 + 强制/补强校验器 + 结构化加载文本 + 口令」。质检仍由 `sd-qc-engine` 执行，本 Skill 只提供**标准与调度口径**，不替代主引擎。

## 两层结构

- **第 0 层 / 常驻层**：`references/pipeline-10stage.md`《全链路通用基线（10 阶段）》——剧本前置→分镜→生成图→图生视频→剪辑转场→字幕→音频→成片→上线终审→异常兜底。**所有项目都叠加这一层**，分「必检 / 风险复检 / 上线终审」，每项带签字栏。
- **第 1～14 层 / 专项层**：题材基线，**一个项目同一时间只锁一套**，在常驻层之上做加严，不许豁免常驻层任何条目。
- **流转闸门**：`references/stage-gate-map.md`《卡点流转表》——给第 0 层的十个阶段加串行闸门：准入凭证、退回节点、风险台账销项、放行签字。要按工序推进或做交接卡点时读它。

## 调用前置：先选题材（硬约束，不选不许用）

**未选定题材 = 不允许使用本 Skill。** 任何人（含 Agent 自己）调用前，必须先把下面 15 项整表呈现给使用人，由使用人**单选一项**；选中后才读清单、才跑校验、才出报告。

- 第 0 套是**常驻层**，在任选题材之上自动叠加，不单独作为一次质检的选择项。
- 一次只锁一套专项题材；换题材必须重新选择并在报告里写明切换原因。
- 使用人未回答前：不得读 `theme-*.md`、不得调校验器、不得生成报告骨架；只能回显这份选项表。
- **不许自动顶替**：不得用「上次用过的那套」、不得按稿件内容反推、不得默认修仙或默认常驻单跑。

## 使用流程

0. **选题材**。按上一节把 15 项交给使用人单选；未选停在这里。
1. **叠两层**。先挂第 0 层（常驻），再叠加选中的那套题材基线（专项）；两层合并成一份生效清单。切题材只换专项层，第 0 层不动。
2. **读基线**。只读 `pipeline-10stage.md` + 命中的那一个 `theme-*.md`，不要全量读 14 套。
3. **逐条校验**。按合并后的清单顺序，**一段一段、一句一句、一镜一镜**核；每段把该段涉及的全部门禁过一遍，不许抽检代表项代替全量。
4. **出报告**。按 `references/report-template.md` 出报告，末尾必须有**技能调用审计栏**与**放行前置待办四表**（准入凭证缺口、台账未销项、缺校验器未完成条目、下一关前置预告）；有替代校验或人工复核位的逐条标出来。待办表只要有一行不是"无"，结论只能是「不可放行」。

## 校验器可用性：清单已按 H3 执行环境清理

清单的「强制 / 补强校验器」列**只保留本机可执行、H3 链路可调用的名字**。原先引用但本机不存在、或与 H3 不通用的 7 类，已按右列替换；清单内不再引用这些名字，**也不需要再提示安装**。

| 原用途 | 现在用什么 |
|---|---|
| 集群 / 大场面构图与队形调度 | `shot-continuity-inspector` 查空间机位；队形、集群合理性列**人工复核位** |
| 服饰形制、朝代正确性 | `costume-consistency-checker` 查一致性；形制正确性列**人工复核位** |
| 行业专业常识（医疗 / 律政 / 刑侦 / 年代） | 无可替代校验器，列**硬性人工复核位**；不复核则该条结论写「未完成」 |
| 通用视频 / 生图生成编排 | 视频走 `minimax-h3`，生图走 `seedream-55` |
| 2.5 视频引擎、Seedream 5.0 生图引擎的专用条目 | H3 链路不适用，**已整体移除** |
| 擦除已烧录字幕（后期修复） | 属后期修复工具，不参与校验；需要时人工处理 |

- 换机器后只以实测为准：`python scripts/qc_lint.py validators --skill <本目录> --roots <技能根> --roots <用户技能根>`（`--roots` 每次只放一个目录，多个就重复写多次）。
- 实测出现缺失项时，才回到老口径：提示安装 + 该条标【人工复核·未自动校验】+ 结论只能写「未完成」。

## 判定口径

- **缺口处理**：清单内校验器已清理为本机可执行项；若在新机器实测出缺失，只提示安装（一句话说明缺哪个），该条标【人工复核·未自动校验】，不因缺技能停掉整份报告。
- **等级**：🔴阻断 = 不修不能流转；🟡一般 = 交付前应修；🟢优化 = 不阻断。
- **缺口即未完成**：某条目引用的校验器缺失且未人工复核，该条结论只能是「未完成」，不能是「通过」。
- **等级归属**：等级由清单定，校验器只报现象，不得自己判等级。
- **同层不双跑**：专项层内不并存两套同类题材基线；第 0 层与专项层可以并存，二者是加严关系不是替代关系。
- **报告即交付**：结论只写在回复里不算交付，必须落到报告文件。

## 自动化（脚本层，确定性部分）

状态、台账、报告骨架、结构自检交给脚本，判断与结论仍归 `sd-qc-engine`。详见 `references/automation.md`。

- `scripts/qc_state.py` —— 项目状态与风险台账。`init / set-genre / get / resolve-genre / stage / todo-add / todo-done / todo-list`
- `scripts/build_report.py` —— 出报告骨架（含审计栏、签字列、待办四表，②表自动填未销项台账）
- `scripts/qc_lint.py` —— 三道自检：`skill`（结构）、`checklists`（清单完整性）、`validators`（校验器存在性，缺的报"需安装"）、`report`（报告必备件）

**题材必选**：用户没给题材时，**不许用上次那套顶替、不许按稿子反推、不许默认常驻单跑**；`init` 缺 `--genre` 直接报错退出并回显 15 项选项，等人选完再继续。

**硬规则**：`qc_lint.py report` 不通过的报告不得交付、不得作为放行依据。

## 按模型分轨（先锁模型，再挑 skill）

同一份清单，投喂层与执行层按模型分轨；**校验层与模型无关，换模型照样跑**。完整矩阵与失效条款见 `references/model-compat-matrix.md`，硬规则：

| 类别 | 包含 | 换模型后 |
|---|---|---|
| A 全模型通用 | 9 个校验器里的 8 个、`short-drama-review`、`short-drama-edit`、`byted-mediakit-*`、`giant-scale-scene`、`script-to-manga`、剧本/决策类引擎 | 不用改，直接跑 |
| B 多模型适配 | `short-drama-director`（总控）、`sd-qc-engine`（C1~C26 / H1~H12）、`sd-feed-engine`（七段式 / H3 六段式）、`novel-storyboard`（默认产 H3 稿）、`sd-combat-engine`、`sd-asset-engine`、`short-drama-produce` | 先锁模型版本，只换投喂层与执行层 |
| C 单模型专用 | `h3-prompt-writing`、`h3-video-prompting`、`minimax-h3`、`qwen3-tts` | 换模型即整套失效，换对应 skill |

- **先锁模型**：`qc_state.py init --model h3|2.5|2.0|seedream|other`，模型写进项目状态，后续分支按它走。
- **失效条款（换模型前逐条查）**：H3 六段式台词块｜H3 段长 4–15 秒硬区间｜15 秒分段硬脚本｜`[SFX:]` 音效标记开关｜H3 声音分层禁台词｜H3 不出画面内字幕条｜字数与图数平台上限｜素材形态 M0/M1/M2。命中项记进报告「缺口与人工复核位」。
- **机检**：`qc_lint.py models --file <投喂稿> --model h3|2.5|2.0`，查稿式与声明模型是否错配（结构错配等于交废稿）。

## 口令模板

- **叠加加载（最常用）**：`sd-qc-engine，加载《全链路通用基线V1（10阶段）》为常驻层 + 《<题材>质检清单V1》为专项层，两层合并为生效清单；专项层只加严不豁免；开启前置盘点与后置审计。`
- **分阶段跑**：`sd-qc-engine，加载生效清单，本次只跑第 <N> 阶段（<阶段名>），逐条出结论与签字栏。`
- **基线初始化**：`sd-qc-engine，加载本项目《<题材>质检清单V1》+ 技能绑定表，冻结为本项目基线；开启前置技能盘点与后置审计；强制校验器不就绪直接终止并告警；判定标准全部引用清单条款；解绑其他题材校验器。`
- **单集终审**：`sd-qc-engine，加载当前生效基线，先做前置技能盘点；按清单顺序逐段逐句逐镜校验，调度全部强制校验器；出对齐清单格式报告，末尾附技能调用审计栏；阻断项标记不可验收；禁止批量盲跑、禁止跳过审计。`
- **脚本前置**：`sd-qc-engine，仅执行脚本&设定模块，调度 short-drama-review 与对应设定校验器；不跑画面音频字幕；出脚本专项报告+审计。`
- **单点抽检**：`<校验器名>，单点抽检<范围>，仅内部参考，不联动完整基线。`（报告顶部标"不可作为验收依据"）

## 禁止项

- 禁止整批盲跑、禁止只信批量脚本结论、禁止抽几条代表全量。
- 禁止引用不存在的校验器名，禁止把缺失校验器写成"已校验通过"。
- 禁止跳过审计栏，禁止用汇总结论代替逐条明细。
- 禁止用本 Skill 的通用文字代替项目自己的设定卡；设定口径以项目文档为准。
